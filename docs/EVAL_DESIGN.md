# Data Agent 评测设计

> 状态：骨架版。v0 跑通后填充具体用例与断言实现。
> 定位：针对本项目 Data Agent 的专用评测体系，不做通用评测平台。

## 1. 评测目标

验证 Data Agent 在以下维度的行为是否符合预期：

- 口径识别与澄清是否正确
- SQL 是否安全（只读、单条、有行数上限）
- 结果异常是否被标记而非静默输出
- 该拒答时是否拒答

## 2. 评测维度

### 2.1 确定性断言（v1 开始实现）

- 安全：非 SELECT / 多语句 / 写操作必须 100% 拦截
- 口径：用户指定“不含税”时，SQL 必须包含税率计算
- 拒答：超出指标定义范围时返回“未识别”，不猜测

### 2.2 Trace 行为断言（v1 后期）

- 工具调用序列是否符合预期（如先门控后生成）
- 错误路径是否记录明确信息

### 2.3 语义质量（v2，可选）

- LLM-as-a-Judge 评估答案完整性、解释合理性
- 需人工抽样校准

## 3. 数据集策略

- 回归集：日常调试用，覆盖核心场景（待填充，目标 15–20 条）
- 挑战集：发布前用，覆盖边界与攻击场景（待填充，目标 10 条）

## 4. 执行与报告

- 每次改 Prompt 或加功能后跑回归集
- 输出通过/失败清单，失败项附 trace 摘要
- 版本对比：改前 vs 改后的通过率变化
